# AI Agent Working Rules (Antigravity)

1. **Code Comments**: All code comments must be written in **Russian**.
2. **Documentation**: All documentation must be stored in the `Docs` folder at the root of the project.
3. **Action Logging**: All actions taken while working on the project must be recorded in the `Docs/CHANGELOG.md` file at the moment of "commit" (task/stage completion).
4. **Structure**: Maintain a clean project structure; place new documentation files only in `Docs`.
5. **Interface Language**: All UI elements must support **three languages**: Russian, English, and Spanish. The interface language should be togglable via a button on the main screen.
6. **Background Execution**: The application must run in the background, save its state upon exit, and restore it upon return.
7. **Documentation Languages**: All documentation must be available in **three languages**: Russian, English, and Spanish.
8. **In-App Documentation**: The application's interface must have a "Documentation" button that opens the documentation in the currently selected interface language.
9. **Development**: If you rewrite code, the old code that you are replacing must be deleted.
