# ControlCortase — Управление моторами через Bluetooth

Приложение управляет двумя двигателями постоянного тока на Raspberry Pi по Bluetooth (RFCOMM/SPP).

## Архитектура
- **Android-приложение**: Kotlin. Сканирует и подключается к BT-устройствам, отправляет команды.
- **Raspberry Pi**: Python (`motor_server.py`). Принимает команды, управляет GPIO.

## Настройка Raspberry Pi

### Железо
- Raspberry Pi 3 B+ (или совместимый с Bluetooth)
- Драйвер L298N, 2x двигатель постоянного тока, аккумулятор

**Подключение по умолчанию:**
- Мотор 1: ENA=BCM25, IN1=BCM23, IN2=BCM24
- Мотор 2: ENB=BCM18, IN3=BCM17, IN4=BCM27

### Программное обеспечение
1. Установить зависимости:
   ```bash
   sudo apt-get update && sudo apt-get install python3-pip python3-rpi.gpio libbluetooth-dev
   pip3 install pybluez
   ```
2. Включить режим совместимости Bluetooth — добавить флаг `-C` к `bluetoothd` в файле службы.
3. Сделать Pi обнаруживаемым через `bluetoothctl`.
4. Запустить: `python3 motor_server.py`

## Настройка Android
1. Открыть папку `android/` в Android Studio.
2. Собрать и установить на Android-устройство с Bluetooth.
3. При первом запуске разрешить доступ к "Nearby Devices" / "Местоположение".

## Использование
1. Запустить `motor_server.py` на Pi.
2. Открыть приложение → нажать Скан (значок 🔍).
3. Выбрать свой Raspberry Pi из списка.
4. Управлять моторами кнопками D-Pad. Ползунок регулирует скорость.

## Команды (Протокол)
Отправляются как строки ASCII, оканчивающиеся на `\n`:
- `FORWARD`, `BACKWARD`, `LEFT`, `RIGHT`, `STOP`
- `SPEED:<0-255>`
- `GET_CONFIG`, `UPDATE`, `RESTART`

## Элементы управления
- **Язык** (значок флага): Переключение между Русским / Английским / Испанским.
- **Справка** (значок ?): Открывает эту документацию.
- **Скан** (значок поиска): Сканирование сопряжённых Bluetooth-устройств.
- **Адмін** (значок шестерёнки): Обновление прошивки, перезагрузка Pi, настройка пинов и WiFi.
