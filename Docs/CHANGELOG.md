# Журнал изменений (CHANGELOG)

## [2026-03-24] — Инверсия моторов и Танковый поворот

### Добавлено
- **Файлы правил**: Добавлены `.cursorrules`, `.windsurfrules` и `.clinerules` на основе `Docs/RULES.md` для автоматического следования правилам проекта всеми AI-ассистентами.
- **Опциональный пин скорости (ШИМ)**: Доработан класс `CustomMotor` и веб-интерфейс. Теперь пин `enable` для управления скоростью можно оставить пустым или установить в `0`, если моторы подключены через перемычку (постоянные 5V). Система корректно обработает отсутствие ШИМ-выхода.
- **Программная инверсия моторов**: В специально созданный класс `CustomMotor` (заменивший `gpiozero.Motor`) добавлен параметр инверсии (`invert`), напрямую управляющий логическими пинами L298N.
- **Опция "Инверсия" в UI**: В веб-интерфейсе во вкладке "Конфигурация" для каждого мотора добавлен чекбокс «Инверсия». Это позволяет менять направление вращения программно, не переподключая провода.

### Исправлено
- **Баг потери роли мотора**: Исправлена ошибка в веб-интерфейсе, из-за которой добавленные или пересозданные моторы не получали системную «Роль» (`move_left` / `move_right`), что приводило к полному игнорированию команд для этого мотора (симптом "крутится только один мотор"). В настройки добавлен выпадающий список для явного выбора роли.
- **Танковое управление**: Алгоритм `process_movement_cmd` на сервере переработан под классическое "танковое" движение (повороты осуществляются вращением колес в противоположные стороны), что исправило несоответствие кнопок физическому движению шасси.


## [2026-03-07] — ROS2 Рефакторинг

### Добавлено (Raspberry Pi — ROS2 Humble)
- Создан ROS2 workspace: `raspberry_pi/controlcortase_ws/`
- Пакет `controlcortase_motor`: узел `motor_controller_node.py`
    - Подписка `/cmd_vel` (geometry_msgs/Twist)
    - Конвертация в дифференциальный привод L298N (GPIO/PWM)
    - Watchdog 500 мс (автостоп при потере связи)
    - Диагностика через `/diagnostics`
    - Параметры GPIO пинов через ROS2 Parameter Server
- Пакет `controlcortase_bluetooth_bridge`: узел `bluetooth_bridge_node.py`
    - RFCOMM сервер с поддержкой переподключения
    - Парсинг устаревшего ASCII протокола → Twist
    - Thread-safe публикация, ACK-подтверждения
    - Watchdog при отключении Bluetooth клиента
- Пакет `controlcortase_bringup`: launch файл + params.yaml
    - `controlcortase_bringup.launch.py` — запуск всех узлов
    - `params.yaml` — конфигурация GPIO и скоростных ограничений
- Документация: `README.md` (установка, сборка, запуск) и `MIGRATION.md`
- Android-приложение **не изменялось** — протокол полностью совместим
